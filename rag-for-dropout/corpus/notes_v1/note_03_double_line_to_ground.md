# Double line-to-ground faults

A double line-to-ground (LLG) fault connects two phase conductors and ground. All three sequence networks take part: the positive-sequence network is in series with the parallel combination of the negative- and zero-sequence networks. In this project the LLG fault types are ABG, BCG and CAG.
