# Three-phase faults

A three-phase fault involves all three phases and is balanced, so only the positive-sequence network is needed. All three phase voltages fall together near the fault. In this project the three-phase types are ABC (without ground) and ABCG (with ground). Three-phase faults are commonly reported as the least frequent fault type in practice, but this dataset contains all 11 types equally.
