# Feeder, sensors, classes and data windows

## System
The study feeder is the IEEE 123-bus distribution test feeder at 4.16 kV line-to-line and 60 Hz. It is simulated in OpenDSS.
The measurement set has 25 μPMU buses (bus 300 is a load/auxiliary bus). The graph used by the model is a 25-node tree with 24 edges between μPMU buses.
There are 25 candidate fault buses; 6 of them are μPMU buses (13, 18, 25, 35, 47, 97) and 19 are not measured directly.

## Classes
The classifier has 26 classes. Class 0 means no fault. Class c from 1 to 25 is the fault bus listed at position c of the sorted fault-bus list: class 1 = bus 7, class 2 = bus 13, class 3 = bus 18, class 4 = bus 21, class 5 = bus 25, and so on (full table in the fault-bus document).

## Scenarios and runs
A scenario is one fault bus, one fault type and one fault resistance: 25 × 11 × 3 = 825 scenarios. Each run of a scenario uses a different load multiplier (range 0.5 to 1.3). The frozen corpus has 50 runs per scenario. A run is named <bus>_<type>_<resistance>_<run>, for example 57_ABCG_10p0_0014 (resistance 10.0 Ω written 10p0).

## Data window
Each run records 60 ms at 1 ms resolution: 40 ms before the fault and 20 ms of fault. A window has 20 time steps (stride 1) and holds, for each of the 25 nodes, 6 channels: 3 RMS phase voltages and 3 availability-mask channels. Shape: [25 nodes, 20 steps, 6 channels]. Each run keeps 40 windows, named w0000 to w0039.

## Window labels
Windows w0000 to w0019 end before the fault and have label 0. Windows from w0020 carry the fault-bus class. Window w0020 ends exactly at fault onset and holds no post-fault sample. A window w ≥ 21 holds w − 20 post-fault samples; w0025 holds 5.

## Splits
The split divides runs, not scenarios, so every scenario appears in train, validation and test. Runs: train 28,875, validation 6,200, test 6,175. Windows: train 1,155,000, validation 248,000, test 247,000.

## Sensor dropout protocol
Dropout removes k of the 25 μPMUs at random, with k in 0, 1, 2, 5 and 10 (0, 4, 8, 20 and 40 percent). A dropped μPMU has its three voltage channels and its three mask channels set to 0; its graph edges stay (policy zero_messages).
