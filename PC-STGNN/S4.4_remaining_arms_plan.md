## 4. Blocks and what removes them

### 4.0 Prerequisite for every arm (tooling, no GPU)
- `config/s4_4/` holds only `r0n.yaml` and `r5.yaml`. Each arm needs its own config.
- `scripts/score_s4_4_gate4_run.py` accepts only `--arm r0n|r5`. It sets `use_fusion = arm == "r5"`
  and builds the model without a type head, a decoder or (for fusion-off arms) a table. A
  checkpoint from R1, R2, R3 or R4 would fail `load_state_dict` (extra keys). The scorer must build
  the model from the arm's saved `config.yaml`.
- `scripts/run_s4_4_gate4.py` has a fixed queue of the 6 Gate 4 runs. It needs an arm list.
- The model loads the R6 shuffled table from the checkpoint buffers (`phys_table`, `shuffle_map`),
  so the scorer gives the shuffled residual without a separate flag. Confirm this in a test.

### 4.1 R3 and R4 (code)
`runner.py` lines 82–93 load the signature table and the norm stats only when `use_fusion` is true.
With fusion off and λ > 0, `forward_pc` has no table, `out` has no `rho_A`/`rho_D`, and
`pc_loss` raises `KeyError("pc_loss needs out['rho_A'] ...")`. Fix: load the table when
`use_fusion` or λ₁ > 0 or λ₂ > 0. Keep the S4.1 null test byte-identical (a buffer does not draw
from the RNG stream) and run `tests/test_pc_stgnn.py` after the change.

### 4.2 R1 and R2 (spec + code)
`PCSTGNN.forward_pc` returns `type_logits` and `recon`, but no loss term reads them (`pc_loss` in
`models/common.py` has none). The heads would train with zero gradient. Needed:
- R1: a cross-entropy term on `type_logits`; the fault-type label from the batch metadata; a
  loss weight. **The weight is not in any document — author decision.**
- R2: a reconstruction loss on `recon` against the dropped sensors (`x_clean`, `drop_mask` from the
  dropout loader); a loss weight; and a definition of "parameter-matched" (matched to what?
  R5 adds 1 parameter; the default decoder adds 64·64+64+64·3+3 = 4,419). **Author decision.**

### 4.3 R6 and R5-γ0 (decision only)
- R6: choose the shuffle-seed value, and say whether the 3 training seeds share one permutation or
  use three. A check that the permutation has no fixed location is advisable (a near-identity
  permutation would not test anything). Not chosen here.
- R5-γ0: the collapse guard (`06` lines 260–265) stops fusion-on arms that collapse at epoch 3 and
  exempts only R8. R5-γ0 is fusion-on, and S4.3ᵈ found the network-only F1 without the auxiliary
  loss at 0.078 (below 0.10). With the guard on, the run stops at epoch 3. Its one claim ("the
  auxiliary loss is necessary for network-only localization", `S4.4_plan_draft.md` decision 3)
  needs the author to choose: exempt it like R8, or accept a stop at epoch 3 as the result.

### 6.2 Implementation plan (no code written)
1. **Decisions first (author):** λ₁, λ₂, γ, β, fusion for B2ᵃ (all TBD in `S4.4_plan_draft.md`
   Part 2); the R̂ target form (log R regression, as the profiling axis is log-spaced, or raw Ω);
   the loss weight; whether R̂ replaces profiling only on the R axis (L and type still profiled).
2. **Labels:** the resistance is in each window's metadata (`resistance` column). Pass it through
   the dataset batch. No-fault windows have no R; mask them out of the R̂ loss.
3. **Head:** an `nn.Linear(gnn_dim, 1)` on the graph embedding, created only when its switch is on
   (after the backbone weights are drawn, as the other heads), so the all-off model stays
   byte-identical to RGSAGE-Max (S4.1).
4. **Residual with R̂:** select the signature-table slice at the R grid point nearest to R̂ (or
   interpolate between the two nearest points) and compute ρ over the other hypothesis axes only.
   The table stays fixed and receives no gradient (`01_SPEC.md` §5). R̂ must never be an argument
   that sends gradient into the table.
5. **Tests (before any run):** all-off byte-identity; no gradient to the table; R̂ loss masked on
   no-fault windows; residual with R̂ = true R equals the profiled residual at that grid point.
6. **Scoring:** the S4.4 validation grid (in-distribution) plus, in Stage G only, the sealed OOD-R
   set split by grounded vs ungrounded (`08_STAGE_G_eval.md` line 30).
